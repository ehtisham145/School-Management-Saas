Jab bhi aap git commit chalate hain, commit hone se pehle Git khud pre-commit chalata hai.
 Yeh 9 checks karta hai:
#	Check	Kya dekhta hai
1	trim trailing whitespace	Line ke aakhir mein faltu spaces, khud hata deta hai
2	fix end of files	File ke aakhir mein khali line, khud laga deta hai
3	check yaml	YAML files mein ghalti (jaise abhi : ke baad space wali)
4	large files	Koi bari file (video, zip) ghalti se na chali jaye
5	private key	Koi secret key ghalti se commit na ho 🔒
6	ruff check	Python code mein galtiyan
7	ruff format	Python code ki formatting
8	eslint	Frontend code mein galtiyan
9	prettier	Frontend code ki formatting
"Skipped" kyun aata hai? Hook sirf badli hui files dekhta hai. Agar aap ne sirf docs badle, to Python aur frontend wale checks ke paas dekhne ko kuch nahi, is liye Skipped. Yeh theek hai.
