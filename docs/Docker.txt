Dockerfile It is used when your app is runnig inside single service single dockerfile is written using the
following docker commands

FROM: This Commmand choose the base enviroment of your app
WORKDIR: Create a folder inside container inside which you will run your app
COPY+RUN: Install Dependencies and COPY 
CMD: The main command used to run the App.

Docker Compose is like a manager who is mainly used for managing your whole app. In Docker-Compose.yml
file we can pull images from docker hub and then convert these images into runnnig containers and it is also
used to convert your project frontend backend separate services convert them into images and then build their
containers and how to build images of your project and convert it into your container is written in Dockerfile
and then this file is called in yml file to build the whole app using one file.
if we don't define the volum in docker compose yaml file inside the db service then every time when you will
